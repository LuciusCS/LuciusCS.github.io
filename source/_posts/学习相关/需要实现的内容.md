4. Dart 脚本解释执行
可以利用 Dart 自带的 dart:eval 库或类似库来动态解析和执行 Dart 脚本代码。这样，更新可以以脚本的形式从服务器端下载，并在客户端解释执行。
例如，将业务逻辑编写成 Dart 脚本文件，客户端下载到本地后通过脚本解释引擎执行。这种方式对逻辑控制较灵活，但不适用于 UI 渲染和 AOT 编译模式下的性能优化。


6. 代码推送服务
第三方服务（如 CodePush）也可以实现某些 Dart 文件的动态更新，但是它通常是通过 JS 层实现的，不算原生 Flutter 的方法。



4. 使用 --split-per-abi 编译
对于 Android 应用，可以使用 --split-per-abi 参数生成不同 ABI 的 APK，这样每个 APK 文件只包含一组平台相关的 native 库，显著减少每个 APK 的大小。
生成指令如下：
flutter build apk --split-per-abi
生成后的文件分别为 armeabi-v7a、arm64-v8a 和 x86_64 等 ABI 的 APK，上传到 Play Store 后会自动分发相应版本。



12. 启用 Lazy Loading（懒加载）
